# package-scala

Scala 3.3 reference library for functional programming, immutable data, and JVM concurrency.

## Layout

| Path | Holds |
| --- | --- |
| `src/main/scala/` | publishable library |
| `src/test/scala/` | JUnit 5 tests |
| `docs/` | usage and release notes |

## Validation

```bash
mvn -q test
```
